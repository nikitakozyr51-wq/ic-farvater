# Создание/обновление страницы

Помоги создать или обновить страницу сайта.

## Перед началом:
1. Прочитай `CLAUDE.md` для понимания структуры проекта
2. Прочитай `docs/REFERENCES.md` для понимания дизайн-направления
3. Прочитай `css/variables.css` для актуальных токенов дизайна
4. Прочитай `css/components.css` для доступных компонентов

## Правила:
- Используй существующие CSS-компоненты и переменные
- Следуй BEM-нотации для новых классов
- Обеспечь адаптивность (mobile-first)
- Добавь мета-теги (title, description)
- Скопируй header и footer из index.html, обнови active-ссылку в навигации
- Пути к CSS/JS: из pages/ используй `../css/`, `../js/`
- Изображения: `alt` + `loading="lazy"` для каталога

## Аргумент:
Передай имя страницы, например: `/build-page about` или `/build-page products`
