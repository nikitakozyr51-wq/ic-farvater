# Получение данных о продуктах

Загрузи данные о продуктах с сайта-источника https://ekb-test.ru/ и обнови каталог.

## Шаги:
1. Открой нужную категорию на ekb-test.ru
2. Извлеки данные: название, описание, характеристики, изображения
3. Обнови массив `products` в `js/products.js`
4. При необходимости создай карточки продуктов в HTML

## Категории для парсинга:
- `/mikroskhemy/` — Микросхемы
- `/razyomy/` — Разъёмы (серии ЕТ-2РМ, ЕТ-2РМГ, ЕТ-2РТТ, ЕТ-СНЦ23)
- `/proizvodstvo-preobrazovatelej-napryazheniya/` — Преобразователи (ИРТЫШ, ВОЛГА, ЕНИСЕЙ, КАМА)
- `/svch-kondensatory/` — СВЧ-конденсаторы (ARC70A, ARC70C, ARC70E)
- `/svch-tranzistory/` — СВЧ-транзисторы LDMOS
- `/proizvodstvo-pechatnyh-plat/` — Печатные платы

## Формат данных в products.js:
```js
{
  id: число,
  name: 'Название',
  category: 'Категория',
  description: 'Описание',
  image: 'URL или путь',
  specs: { 'Параметр': 'Значение' }
}
```

## Аргумент:
Передай категорию: `/fetch-products разъёмы` или `/fetch-products все`
