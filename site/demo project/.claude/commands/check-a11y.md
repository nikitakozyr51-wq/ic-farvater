# Проверка доступности (a11y)

Проверь сайт на соответствие базовым требованиям доступности (WCAG 2.1 Level A).

## Проверки:
1. **Контрастность** — текст читается на фоне? Проверь основные комбинации цветов из `css/variables.css` (минимум 4.5:1 для текста, 3:1 для крупного текста)
2. **Клавиатурная навигация** — все интерактивные элементы доступны через Tab? Есть фокусные стили?
3. **Скринридеры** — изображения имеют alt? Декоративные элементы скрыты от скринридеров? Есть skip-navigation ссылка?
4. **Формы** — все поля имеют label? Ошибки валидации объявляются?
5. **Семантика** — используются правильные HTML-теги? Заголовки идут по порядку?
6. **ARIA** — aria-label на кнопках без текста (бургер-меню)?

## Формат:
Для каждой проблемы: файл, строка, описание, приоритет (критично/важно/желательно).
