# Проверка соответствия стилю

Проверь текущий код сайта на соответствие дизайн-системе, описанной в референсах.

## Что проверить:

1. **Цветовая палитра** — все цвета берутся из CSS-переменных в `css/variables.css`? Нет захардкоженных цветов в HTML (кроме inline для прототипирования)?

2. **Типографика** — используются размеры из `--text-*` переменных? Иерархия заголовков правильная (h1 > h2 > h3)?

3. **Отступы** — используются `--space-*` переменные? Нет магических чисел?

4. **Компоненты** — классы следуют BEM-нотации (`block__element--modifier`)? Переиспользуемые элементы вынесены в `components.css`?

5. **Соответствие референсам** — прочитай `docs/REFERENCES.md` и сравни текущую реализацию с описанными решениями. Особенно:
   - Минималистичная навигация (как Artera)
   - Крупная типографика (как Andermatt/Quadrant)
   - Продуктовая сетка (как Artera)
   - Синяя цветовая схема (как BlueShield)
   - Статистика крупными цифрами (как Quadrant)

6. **Адаптивность** — есть media queries для mobile (480px), tablet (768px), desktop (1024px)?

## Формат ответа:
Для каждой проблемы укажи:
- Файл и строку
- Что не так
- Как исправить

Если всё хорошо — подтверди соответствие.
