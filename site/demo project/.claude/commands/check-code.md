# Проверка качества кода

Проведи полную проверку HTML, CSS и JS кода проекта `ic farvater/`.

## HTML проверки:
- [ ] Валидный HTML5 (doctype, lang, charset, viewport)
- [ ] Семантические теги (header, nav, main, section, footer, article)
- [ ] Все изображения имеют `alt` атрибуты
- [ ] Каталожные изображения имеют `loading="lazy"`
- [ ] Формы имеют `label` для каждого `input`
- [ ] Кнопки и ссылки имеют понятный текст или `aria-label`
- [ ] Нет дублирования `id`
- [ ] Мета-теги заполнены (title, description)

## CSS проверки:
- [ ] Нет неиспользуемых классов
- [ ] Нет дублирующихся свойств
- [ ] Все цвета через CSS-переменные
- [ ] Нет `!important` (кроме крайних случаев)
- [ ] Media queries идут от mobile к desktop
- [ ] Нет вендорных префиксов без необходимости

## JS проверки:
- [ ] Нет `var`, только `const` и `let`
- [ ] Нет `document.write`
- [ ] Event listeners добавляются после DOMContentLoaded
- [ ] Нет утечек памяти (listeners при удалении элементов)
- [ ] Нет XSS-уязвимостей (экранирование innerHTML)
- [ ] Функции имеют понятные имена

## Общие проверки:
- [ ] Все файлы в UTF-8
- [ ] Отступы: 2 пробела
- [ ] Нет закомментированного кода без причины
- [ ] Нет console.log в продакшен-коде

## Формат ответа:
Список найденных проблем с указанием файла, строки и рекомендации по исправлению.
