# IC Farvater — Website Redesign

## Project Overview
Редизайн сайта компании-дистрибьютора "ИК Фарватер".
Многостраничный сайт на чистом HTML + CSS + JS (без фреймворков).

## Tech Stack
- **HTML5** — семантическая разметка
- **CSS3** — кастомные свойства (CSS variables), Flexbox, Grid, адаптив через media queries
- **JavaScript (ES6+)** — vanilla JS, модули
- **Шрифты** — подключаются локально через `assets/fonts/`
- **Без сборщиков** — проект работает как есть, без npm/webpack/vite

## Data Source
- **Сайт-источник:** https://ekb-test.ru/ (ООО «ЭКБ ТЕСТ»)
- **Компания:** Интегратор комплексных решений в микроэлектронике, Санкт-Петербург
- **Продукция:** Микросхемы, разъёмы (ЕТ-серии), преобразователи напряжения (ИРТЫШ, ВОЛГА, ЕНИСЕЙ, КАМА), СВЧ-конденсаторы (ARC70), СВЧ-транзисторы LDMOS, печатные платы
- **Услуги:** Испытательная лаборатория, импортозамещение, проектирование, контрактный монтаж, поставки ЭКБ

## Design Direction
- **Стиль:** Чистый минимализм с акцентом на продуктах (BlueShield reference)
- **Типографика:** Крупные заголовки, контрастная иерархия
- **Сетка:** CSS Grid для каталога, Flexbox для компонентов
- **Цвета:** Синяя палитра (BlueShield-inspired) — `#4A7AFF` акцент, белый фон, тёмный текст
- **Адаптив:** Mobile-first подход

## Coding Conventions
- Все файлы в кодировке UTF-8
- CSS классы в формате BEM: `block__element--modifier`
- Отступы: 2 пробела
- Комментарии на русском для контента, на английском для кода
- HTML атрибуты: двойные кавычки
- Изображения: всегда указывать `alt`, использовать `loading="lazy"` для каталога

## Pages
1. **Главная** (`index.html`) — hero-секция, ключевые продукты, преимущества, CTA
2. **О компании** (`pages/about.html`) — история, миссия, команда
3. **Услуги** (`pages/services.html`) — список услуг дистрибьютора
4. **Продукты** (`pages/products.html`) — каталог с поиском и фильтрацией
5. **Карточка продукта** (`pages/product-detail.html`) — детали, характеристики, изображения
6. **Контакты** (`pages/contacts.html`) — форма связи, карта, реквизиты

## Workflow
1. Дизайн сначала в коде (HTML/CSS), потом перенос в Pencil (MCP-сервер)
2. Референсы хранятся в `assets/reference/`
3. Продукты и изображения парсятся с https://ekb-test.ru/
4. Проект должен быть портативным — работает с любого ПК без установки зависимостей

## Available Skills (slash commands)
Скиллы находятся в `.claude/commands/` и вызываются через `/command-name`:

| Команда | Описание |
|---------|----------|
| `/check-style` | Проверка соответствия дизайн-системе и референсам |
| `/check-code` | Проверка качества HTML/CSS/JS кода |
| `/check-a11y` | Проверка доступности (WCAG 2.1) |
| `/build-page` | Создание/обновление страницы по шаблону |
| `/fetch-products` | Получение данных о продуктах с ekb-test.ru |
| `/review` | Полный обзор состояния проекта |
| `/design-search` | Поиск стилей, цветов, шрифтов в базе UI/UX Pro Max |

## External Tools

База данных дизайн-решений: стили, палитры, шрифты, UX-паттерны.

```bash
node .claude/skills/ui-ux-pro-max/scripts/search.mjs "<запрос>" --domain <product|style|color|typography|landing|chart|ux>
```
