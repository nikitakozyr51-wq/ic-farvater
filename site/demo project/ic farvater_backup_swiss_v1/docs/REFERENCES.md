# Анализ референсов

## Общий стиль
Из всех референсов выделяется направление: **современный минимализм с акцентом на продукте**.
Чистый белый/светлый фон, крупная типографика, много воздуха, качественные фото продуктов.

---

## 1. Artera (artera referense.png, artera product referense.png)
**Что взять:**
- Минималистичная сетка продуктов (CSS Grid, 3-4 колонки)
- Большие фото продуктов на белом фоне
- Простая навигация в шапке (лого слева, меню по центру, иконки справа)
- Категории продуктов как отдельные блоки-секции
- Footer с колонками (бренд, поддержка, соцсети, подписка)

**Цветовая схема:** Почти монохром — белый фон, черный текст, минимум цвета

---

## 2. Andermatt (andermatt referense.png)
**Что взять:**
- Крупный hero-заголовок (большой шрифт, жирный, занимает ~50% экрана)
- Красные/яркие акценты для выделения важного
- Асимметричная сетка (текст + изображение не 50/50)
- Текстурный фон (мрамор/камень) для разнообразия секций

**Цветовая схема:** Белый + черный + красный/оранжевый акцент

---

## 3. BlueShield (blueshild reference.png, blueshild referense 2.png)
**Что взять:**
- Структура каталога с характеристиками продуктов (таблица свойств)
- Навигация: Каталог, О нас, Мобильное приложение, Контакты
- Карточка продукта: фото справа, характеристики слева (сетка свойств)
- Цветные бейджи для сертификатов/стандартов (ASTM, GMP, ISO)

**Цветовая схема:** Белый + синий акцент

---

## 4. Blink (blink reference.png)
**Что взять:**
- Яркий акцентный цвет (бирюзовый/cyan)
- Интерактивные элементы с визуальной обратной связью
- Скругленные элементы интерфейса

**Цветовая схема:** Темный фон + бирюзовый акцент

---

## 5. Quadrant (quarant referense.png)
**Что взять:**
- Строгая корпоративная типографика
- Крупные цифры/статистика как элемент дизайна (32%, 84%)
- Секция "О нас" с ключевыми метриками
- Чередование белых и темных секций

**Цветовая схема:** Черный + белый, без цветных акцентов

---

## Синтез: Что берем для IC Farvater

| Элемент | Источник | Решение |
|---------|----------|---------|
| Навигация | Artera | Чистая шапка: лого + меню + поиск |
| Hero-секция | Andermatt + Quadrant | Крупный заголовок + ключевые цифры компании |
| Каталог | Artera | Grid-сетка карточек с фото |
| Карточка продукта | BlueShield | Фото + таблица характеристик |
| Цветовая схема | Artera + Andermatt | Белый фон, темный текст, 1 акцентный цвет |
| Типографика | Quadrant + Andermatt | Крупные заголовки, контрастная иерархия |
| Footer | Artera | Колонки с навигацией и контактами |

## Утверждённая палитра (BlueShield-inspired)

```
--color-bg:           #FFFFFF   /* Основной фон */

--color-bg-dark:      #1A1A2E   /* Тёмный фон (footer) */
--color-text:         #1A1A2E   /* Основной текст */
--color-text-muted:   #6B7280   /* Вторичный текст */
--color-accent:       #4A7AFF   /* Основной синий акцент */
--color-accent-hover: #3560E0   /* Акцент при наведении */

```
