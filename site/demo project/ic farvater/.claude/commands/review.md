# /review

Полный аудит сайта IC Фарватер — как студия, а не новичок.

## Запусти проверку по 5 категориям:

### 1. Дизайн (визуальное качество)
- Соответствие дизайн-системе (см. /check-style)
- Визуальная иерархия на каждой странице
- Консистентность компонентов (хедер, футер, карточки)
- Пустое пространство (whitespace) — достаточно ли воздуха?

### 2. UX (пользовательский опыт)
- Интерактивные состояния: hover, active, focus на всех элементах
- Навигация: понятно ли где пользователь?
- CTA (призывы к действию): заметны ли?
- Мобильная версия: работает ли меню, читается ли текст?

### 3. Производительность
- Изображения: есть ли loading="lazy"?
- Шрифты: подключены ли локально или через Google Fonts?
- Лишние HTTP-запросы?

### 4. Доступность (a11y)
- alt у всех изображений?
- Контрастность: #0033FF на #FFFFFF — проходит WCAG AA?
- focus-visible на интерактивных элементах?
- aria-label на иконках и кнопках без текста?

### 5. SEO
- title и meta description на всех страницах?
- Семантические теги (header, main, section, footer)?
- h1 один на странице?
- og:image и og:title?

## Формат ответа
Таблица: Категория | Статус (✓/⚠/✗) | Проблема | Файл
Потом — топ-5 приоритетных правок.
