# /polish

Финальная полировка — делаем сайт уровня студии.

## Чеклист "агентства vs новичка"

### Микроанимации
- [ ] Плавный появление элементов при скролле (уже есть scroll-reveal)
- [ ] Hover на карточках продуктов: тень или смещение
- [ ] Плавные переходы между страницами (fade)
- [ ] Кнопки: transform scale(0.98) при нажатии

### Типографические детали
- [ ] Все заголовки — UPPERCASE
- [ ] Числа в скобках как в Esmée Van Arden: (01), (02)
- [ ] Консистентные разделители секций

### Визуальные детали
- [ ] Линия-разделитель под хедером (border-bottom: 1px solid var(--color-border))
- [ ] Фавиконка установлена?
- [ ] Состояние загрузки для изображений (skeleton или blur)
- [ ] 404 страница?

### Взаимодействие
- [ ] Форма контактов: валидация + сообщение об успехе
- [ ] Поиск в каталоге: сообщение "ничего не найдено"
- [ ] Скролл наверх кнопка (на длинных страницах)

### Профессиональные мелочи
- [ ] cursor: pointer на всех кликабельных элементах
- [ ] selection цвет (::selection { background: #0033FF; color: #fff; })
- [ ] Scrollbar стилизован или скрыт
- [ ] Print стили (display:none для nav/footer при печати)
