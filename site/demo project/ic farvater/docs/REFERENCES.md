# Анализ референсов — ИК Фарватер

## Стиль
**Швейцарский международный типографический стиль (Swiss International Typographic Style)**
Чёрно-белая основа, строгая сетка, крупная типографика, много воздуха, акцентный цвет только для текстовых выделений.

---

## 1. Quadrant Capital (quadrantcapital.io)
**Главный референс — структура и типографика**
- Строгая корпоративная типографика, крупные заголовки
- Крупные цифры/статистика как элемент дизайна
- Чёрно-белая палитра, чередование белых и тёмных секций
- Много пустого пространства, ровная сетка

---

## 2. Andermatt
**Hero-секция**
- Крупный hero-заголовок (большой шрифт, жирный, занимает ~50% экрана)
- Швейцарский альпийский стиль — чистота, строгость
- Изображение + крупный uppercase заголовок

---

## 3. Esmée Van Arden (каталог)
**Каталог продуктов и акцентный цвет**
- Uppercase текст на карточках
- Акцентный цвет на названиях продуктов и ссылках
- Квадратная сетка продуктов
- Строгая типографическая иерархия

---

## 4. Blink Loto (dprofile.ru/case/166691/blink-loto)
**Использование шрифта Inter**
- Inter в разных весах и размерах
- Чистые интерфейсы, хорошая читаемость

---

## Синтез: Что берём для ИК Фарватер

| Элемент | Источник | Решение |
|---------|----------|---------|
| Типографика | Quadrant + Blink Loto | Inter, размеры 50/40/32/16/14/12px, uppercase заголовки |
| Hero-секция | Andermatt | Изображение + крупный uppercase заголовок |
| Структура | Quadrant Capital | Строгая сетка, секции с метриками, чередование |
| Каталог | Esmée Van Arden | Квадратная сетка, uppercase, акцентный цвет текста |
| Палитра | Quadrant + Esmée | Чёрно-белая основа + один акцентный цвет |
| Сетка | Swiss Style | 8px grid, ровные отступы (UI/UX Pro Max) |
| Footer | Quadrant | Тёмный фон, колонки, строгая типографика |

## Утверждённая палитра (Swiss B&W + Accent)
```
--color-bg:         #FFFFFF   /* Основной фон */
--color-bg-alt:     #F5F5F5   /* Альтернативный фон */
--color-text:       #000000   /* Основной текст */
--color-text-muted: #666666   /* Вторичный текст */
--color-text-light: #AAAAAA   /* Третичный текст */
--color-border:     #E0E0E0   /* Границы */
--color-accent:     #156BD6   /* Акцент — только для текстовых выделений */
--color-white:      #FFFFFF   /* Белый */
--color-black:      #000000   /* Чёрный */
```

## Шрифт
- **Inter** — единственный шрифт
- Размеры: 50px (h1), 40px (h2), 32px (h3), 16px (body), 14px (small), 12px (caption)
- Веса: 400, 500, 600, 700

## Сетка
- 8px grid system (UI/UX Pro Max)
- Отступы: 4/8/16/24/32/48/64/80/120/160px
- Контейнер: 1200px, padding 40px
- Gutter: 32px
