ЧТО СКОПИРОВАТЬ НА ФЛЕШКУ / ОБЛАКО:
------------------------------------

1) Этот файл (SETUP_NEW_PC.txt)

2) Pencil-макет:
   C:\Users\Валентина\.vscode\extensions\highagency.pencildev-0.6.35\out\data\pencil-new.pen

3) Папка memory (вся целиком):
   C:\Users\Валентина\.claude\projects\e--site\memory\


НА НОВОМ ПК:
------------------------------------

ШАГ 1 — Установить:
  - VS Code (https://code.visualstudio.com)
  - Расширение Claude Code (Anthropic) — в маркетплейсе VS Code
  - Расширение Pencil (highagency.pencildev) — в маркетплейсе VS Code
  - Git (https://git-scm.com)

ШАГ 2 — Склонировать репозиторий:
  Открыть терминал, выполнить:
    git clone https://github.com/nikitakozyr51-wq/ic-farvater.git
  Папку можно положить куда удобно, например E:\site\ic farvater\

ШАГ 3 — Скопировать Pencil-файл:
  Найти папку расширения Pencil:
    C:\Users\<ИМЯ>\.vscode\extensions\highagency.pencildev-<ВЕРСИЯ>\out\data\
  Положить туда файл pencil-new.pen с флешки.

ШАГ 4 — Скопировать память Claude:
  Создать папку (путь зависит от расположения проекта):
    C:\Users\<ИМЯ>\.claude\projects\<ID-ПРОЕКТА>\memory\
  Положить туда все .md файлы из папки memory с флешки.
  (ID проекта создастся автоматически при первом запуске Claude Code
   в папке проекта — просто найди новую папку в .claude\projects\)

ШАГ 5 — Открыть проект в VS Code:
  File → Open Folder → выбрать склонированную папку ic-farvater

ШАГ 6 — Написать Claude:
  Открыть Claude Code и написать:

  «Настрой рабочее окружение для проекта IC Фарватер.
   Прочитай CLAUDE.md и проверь что всё на месте:
   - код из репозитория
   - pencil-new.pen открывается в Pencil
   - memory файлы подхватились
   Покажи скриншот главной страницы из Pencil для проверки.»
