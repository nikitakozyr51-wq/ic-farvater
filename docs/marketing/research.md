## 3. Конкурентная картина (кратко; детально — _summary.md)

> **ПОПРАВКА заказчика (2026-07-13):** ekb-test.ru / «ЭКБ ТЕСТ» — **НЕ конкурент**, а партнёрская лаборатория IC (ею пользуемся) и источник данных/линеек каталога. Файл `_summary.md` частично написан до этой поправки и разбирает ekb-test как «прямого конкурента» — читать этот разбор как контекст партнёра-поставщика, НЕ как соперника. Карта рынка и выводы о видимости остаются в силе.

- **Прямых сильных конкурентов в нише почти нет.** Профильный спец-ЭКБ для ОПК со складом + подбором аналогов + документами + доступом к лаборатории — поле слабо занято. Это переносит фокус стратегии с «победить конкурента» на «стать видимым».
- **Кандидаты в прямые конкуренты** (уточнить у заказчика): крупные/профильные дистрибьюторы ЭКБ — macrogroup.ru, platan.ru, compel, icgamma.ru, fregat.ru, inelso.ru (фигурировали в прошлых сессиях). Реальное пересечение по нише подтвердить.
- **Вторичные — по категориям:** продавцы разъёмов (asenergi, ipelectron, ruelectronics) торгуют базовым 2РМГ, не фирменной ЕТ-серией; нет ГОСТ РВ, лаборатории, подбора аналогов, сборок по КД. Перехватывают родовой трафик, но не бьются за профильного ОПК-заказчика.
- **Апстрим-производители** (niiet.ru, pulsarnpp.ru): вендоры LDMOS/микросхем — поставщики для каталога IC. НИИЭТ был на техобслуживании → окно забрать трафик по их сериям.
- **Главная возможность:** квадрант «современный сайт + глубокий спец-ЭКБ» пуст. Экспертный контент в нише отсутствует у ВСЕХ (ни блога, ни кросс-таблиц аналогов, ни калькулятора подбора) — самый дешёвый и защищённый вектор отстройки.

## 4. Критический аудит старого SEO-плана (почему не берём за основу)

Старый план (`docs/seo/ПЛАН-ДЛЯ-ЗАКАЗЧИКА.md`, 27.05) = хороший склад активов, но как стратегия непригоден:

1. **Разрыв v1↔v2:** заявленная «завершённая» schema-работа (FAQPage, Product×6, Service×4, SearchAction) сделана на v1 и НЕ переехала на живой v2 — на проде её нет. «Этап 1 завершён» на проде не существует.
2. **Противоречие цифр:** план обещал «12 страниц в sitemap» и мониторинг «12 в индексе» — фактически sitemap = 5 URL.
3. **Пропущен главный рычаг:** 767 товаров за одной JS-страницей → каталог невидим для поиска. Старый план про генерацию страниц серий/товаров молчит. Это упущено — и это причина, почему по артикулам сайта нет в топе.
4. **Бюджет постулирован без подтверждения** (Год 1 = 190–260 тыс ₽/мес, 2.3–3.1 млн ₽/год, split 70/30) — методология marketing-plan прямо называет это failure mode. → 3 сценария.
5. **Несогласованный scope контента:** «15–20 статей» / таблица на 20 / README на 12. Берём фактические 12, приоритет 4–6.
6. **План простоял 6 недель без движения** (нет Я.Бизнес, 2ГИС, отзывов; статьи не опубликованы) — был слишком «толстым» для несведущего заказчика. → короткий чеклист простым языком + чёткое «заказчик vs Валентина».
7. **Метрика — двусмысленный статус** (см. §2), пометить «проверить в кабинете».
8. **Устаревший бенчмарк:** апрельский SEO-AUDIT мерил v1 на github.io, бенчмарк chipdip (ритейлер, не прямой конкурент), Health 18/100 — неактуально. Прямой конкурент — ekb-test.

**Переиспользуем точечно:** 12 готовых статей (`docs/articles/`), тексты Я.Бизнес/2ГИС и шаблоны отзывов (`etap-2-catalogs.md` — после copy-editing), реалистичный таймлайн ТОП.

## 5. Открытые решения (ранжировано по влиянию)

1. **Бюджет заказчика на рекламу** — определяет, включаем ли Я.Директ (быстрые заявки) или только органика. Блокирует выбор сценария в Section 10.
2. **Перепроверка в Яндексе (гео РФ).** Вся SERP-разведка — Google US-локаль. Реальные покупатели ЭКБ ищут в Яндексе; позиции, конкуренты и видимость там иные. Нужно: подтвердить сайт в Я.Вебмастере (регион СПб), снять реальные позиции по 15–20 запросам, проверить индексацию. Семантические ложняки подтверждают риск: «ИРТЫШ»→насосы, «ЭТВА»→тиристорные электроприводы.
3. **Статус лаборатории «ЭКБ Тест»** — как позиционировать партнёрскую лабораторию (услуга IC) без юр-рисков в формулировках.
4. **Живая регистрация Метрики** — счётчик 109423767 реально собирает данные? (кабинет Метрики).
5. **Факты, требующие подтверждения заказчиком** (для материалов): цены/наценка/мин.сумма, конкретные референс-проекты/кейсы (публиковать только с согласованием), точное число позиций каталога.

**Дисциплина фактов:** ни одну цифру из профилей конкурентов НЕ цитировать в наших материалах без независимого подтверждения (все помечены во «Флагах достоверности» _summary.md). Наши собственные цифры — только из проверяемых источников (бренд-бук запрещает «12+ лет», «собственная лаборатория», «ВП», «1.2k+ артикулов» и т.п.).
