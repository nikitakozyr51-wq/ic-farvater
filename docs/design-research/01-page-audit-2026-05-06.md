# Аудит главной страницы IC Farvater — 2026-05-06

Полный разбор `index.html` секция за секцией. Каждая секция: что есть → проблемы → предложения.

Опирается на: Müller-Brockmann «Grid Systems» (модульная сетка), Hurlburt «The Grid», Rousselle «Le Minimalisme Web», NN/g (Закон близости), Every Layout (Heydon Pickering), референсы regrocery.co + minimal.gallery e-commerce.

## 1. Header — `[index.html:40-75](../../index.html)`

### Что есть
- Sticky 64px высоты
- Logo слева, nav справа: search + 4 ссылки (Каталог / О компании / Услуги / Контакты)
- Иконка поиска раскрывается в инлайн-инпут
- На мобиле — бургер

### Что хорошо
- Lean минималистичный паттерн (Pentagram, Linear, Vercel)
- Search-toggle вместо постоянного поля — экономит пространство
- Uppercase-ссылки в `--color-text-muted` с hover в `--color-text` — читается как «editorial»

### Проблемы и предложения
1. **Нет индикации активной страницы.** `.header__link--active` определён в CSS, но нигде не присвоен в HTML (кроме как через JS — нужно проверить). На главной все ссылки серые. **Рекомендация:** при загрузке страницы добавлять `--active` к ссылке текущего раздела. Это не «оживляет» дизайн, а помогает ориентации (закон NN/g «You-are-here»).
2. **Логотип с `letter-spacing: 1px` + weight 700 — слишком жирный для Swiss-стиля.** Pentagram, Quadrant Capital, Aesop ставят логотип в weight 500–600 без letter-spacing или с минимальным +0.5px. **Рекомендация:** weight 600, letter-spacing 0.5px.
3. **Border-bottom хедера отсутствует.** Когда страница скроллится, контент «упирается» в хедер без визуальной границы. Multiple sites (Linear, Vercel) используют 1px hairline border-bottom при скролле. **Рекомендация:** добавить `border-bottom: 1px solid var(--color-border)` (можно появляющуюся через JS при scroll > 0).

## 2. Hero — `[index.html:78-88](../../index.html)`, [components.css:239-317](../../css/components.css)

### Что есть
- Высота 780px фиксированная
- Background image full-bleed, `object-fit: cover`, `object-position: left center`
- H1 `position: absolute, top: 280px` (72px, weight 500, letter-spacing −2px)
- Subtitle `top: 532px` (16px, body)
- CTA-pill `top: 634px`

### Проблемы

1. **Абсолютное позиционирование пикселями.** Три абсолютных элемента с `top: 280px / 532px / 634px` — это анти-паттерн Müller-Brockmann (модули должны быть пропорциональными). При смене контента (более длинный H1) элементы пересекутся.
2. **Большой gap между H1 и subtitle:** 532 − 280 = 252px. При высоте H1 ~227px (3 строки × 72×1.05) → пустое пространство ~25px между ними нормально. Но при subtitle → CTA: 634 − 532 = 102px, при высоте sub ~50px → 52px пустоты. Слишком много для группы «лид + кнопка». Должно быть 24–32px.
3. **Высота 780px — произвольная.** Не модуль. Müller-Brockmann требует кратность line-height. 780 / 24 = 32.5 — некратно.

### Предложение
Заменить абсолютное позиционирование на flex column:

```css
.hero {
  height: 720px; /* 720 = 30 * 24 — кратно модулю */
  display: flex;
  align-items: flex-end; /* контент в нижней трети, как у Aesop */
  padding-bottom: 96px; /* 4 * 24 */
}
.hero .container {
  display: flex;
  flex-direction: column;
  gap: 24px; /* H1 → sub: один модуль */
}
.hero__btn {
  margin-top: 24px; /* sub → CTA: ещё один модуль */
}
```

Это ровно паттерн Aesop / Norse Store / In Common With: контент прижат к нижней трети hero, всё связано вертикально.

## 7. Преобразователи напряжения (banner) — `[index.html:274-291](../../index.html)`, [components.css:570-621](../../css/components.css)

### Что есть
- Full-width image с `aspect-ratio: 1320/580` (≈ 2.276)
- Контент `position: absolute, bottom: 60px, left: 69px`
- Label (метка) + Title (40px) + 2 кнопки (white-solid + white-outline)

### Что хорошо
- Banner-with-overlay — классический паттерн (Norse Store hero, Linear product CTA)
- Hover: `transform: scale(1.02)` на изображении — Esmée Van Arden / Topicals тактика
- Две кнопки с разными priority (solid + outline) — Refactoring UI правило (один primary CTA)

### Проблемы и предложения

1. **`left: 69px` — странное число.** Откуда? Базовый паддинг секции `var(--container-padding)` = 60px на десктопе. 69 − 60 = 9px. Либо это историческая ошибка, либо попытка визуально сместить от края изображения. **Рекомендация:** заменить на `left: var(--container-padding)` или `left: 60px` — кратность модулю.

2. **`bottom: 60px` + `gap: 16px` между label/title/btns.** Норма. Но 60px от низа при высоте баннера 580px — это почти 10% высоты — нормально для «editorial bottom-anchor» (Aesop, Norse Store). Можно оставить.

3. **Label сверху title.** Это «kicker» паттерн (журнальная подача). Хорошо. У regrocery «STAY IN THE LOOP» аналогично. Но желательно `letter-spacing` ~1.5–2px, у тебя 1px — допустимо.

4. **Aspect-ratio 1320/580 (≈2.28)** — близко к классическому золотому 2.236. ОК. Но можно поэкспериментировать с 16:9 (1.78) если хочется более кинематографичной картинки.

## 8. Импортозамещение — `[index.html:294-325](../../index.html)`, [components.css:623-679](../../css/components.css)

### Что есть
- `section-header-v2--plain` (только title + counter `(04)`, без desc и border-bottom)
- Grid: 2 карточки в ряд, gap 24px
- Карточка: img 600px × auto + title (14px label) + desc (14px text-muted)

### Проблемы и предложения

1. **`section-header-v2--plain`** убирает border-bottom и desc. Это OK для секций без подзаголовка, но **разрыв ритма** — у предыдущих секций был border-bottom, а здесь нет. **Рекомендация:** добавить хотя бы короткий `desc` (одно предложение про «что мы делаем в импортозамещении») и оставить border-bottom — единая структура заголовка.

2. **Высота карточки `height: 600px`** — фиксированная. Опять не модуль. **Рекомендация:** заменить на `aspect-ratio: 4/5` (480px высота при 600px ширине — кинематографичный портрет, как у Topicals products) или `aspect-ratio: 3/4`.

3. **Title 14px + desc 14px, оба uppercase, letter-spacing 1px.** При близких размерах title теряется — нет иерархии. **Рекомендация:** title — 16px weight 600, desc — 14px weight 400 (как сейчас). Или наоборот: title bigger 18–20px, чтобы был контраст. Müller-Brockmann: «соседние уровни иерархии должны различаться минимум в 1.25×».

4. **Hover: `translateY(-6px)`** — нормальная микроанимация. Но у Aesop / Norse Store карточки **не двигаются** — меняется только background или underline на title. Стилистический выбор.

## 9. Услуги — `[index.html:329-402](../../index.html)`, [components.css:809-...]

### Что есть
- Split: левый блок 480px (title 40px + desc + CTA pill solid) + правый блок (4 аккордеона)
- gap: 80px между ними
- Padding: 80px / 60px

### Проблемы и предложения

1. **Width 480px фиксированный** — снова анти-паттерн. **Рекомендация:** `grid-template-columns: 1fr 2fr` или `5fr 7fr` (асимметрия — Topicals-style).

2. **Заголовок «УСЛУГИ» 40px** — без counter `(05)`! Все секции выше имеют counter, а эта — нет. **Разрыв системы.** **Рекомендация:** добавить `(05)` рядом.

3. **Аккордеоны без видимых границ снизу при свёрнутом состоянии.** Service-item header — кнопка с title + icon (стрелка). Желательно `border-bottom: 1px solid var(--color-border)` на каждом item — это даст «список» вместо «бесформенной кучи». Quadrant Capital делает именно так.

4. **CTA «Связаться» — solid pill в `--color-text` (синий).** OK для primary CTA. Но это уже **второй** primary в секции (первый был «КАТАЛОГ» в продуктовых блоках). На Refactoring UI чётко: «один primary на screen». Можно оставить — но осознанно: если «КАТАЛОГ» становится outline, то «Связаться» остаётся solid.

## Сквозные системные проблемы (не одна секция)

### A. Спейсинг между секциями неконсистентный
Разные секции имеют:
- `padding: 80px 60px` (about-block, services)
- `padding: 80px 0 60px` (product-banner)
- `padding: 80px var(--container-padding)` (cables)

**Рекомендация:** ввести один токен `--section-padding-y: 80px` и использовать везде. Не смешивать `60px` и `80px` без причины.

### B. Counter `(00)` не везде
- `(01)` Разъёмы ✓
- `(02)` Дистрибьютор — НЕТ (исправлено в Pencil)
- `(03)` СВЧ-компоненты ✓
- ??? Кабельные сборки — НЕТ (исправлено в Pencil)
- `(04)` Импортозамещение ✓
- ??? Услуги — НЕТ

Нумерация скачет: 01, 02 (кабельные), 03, 04, 05. **Рекомендация:** перенумеровать после правок: 01-Разъёмы / 02-Дистрибьютор / 03-СВЧ / 04-Кабельные / 05-Преобразователи / 06-Импортозамещение / 07-Услуги.

Но тут спорный вопрос: считать ли banner «Преобразователи» отдельной секцией? У regrocery счётчики не на каждой секции. **Альтернатива:** counters только на product-секциях (Разъёмы 01 / СВЧ 02 / Кабельные 03 / Импортозамещение 04) — без Дистрибьютор и Услуги.

### C. Border-bottom между секциями неконсистентен
- `.section--bordered` применяется не везде (cables, импортозамещение, services)
- About-block — без `--bordered`

**Рекомендация:** все секции либо имеют тонкий разделитель снизу (1px `--color-border`), либо ни одна. Я бы выбрал «все имеют», кроме first (hero) и last (footer).

### D. Микс flex и grid
Часть секций на flex (about-block, cables), часть на grid (bottom-cards `display: flex` тоже). Müller-Brockmann требует один скелет. **Рекомендация:** макро-разбиение секций — Grid (`display: grid; grid-template-columns: ...`), внутри ячеек — Flex для стека. Это совет MDN и Every Layout.

### E. Фиксированные пиксельные размеры
Перечень: `width: 553px`, `width: 648px`, `width: 720px`, `height: 530px`, `height: 760px`, `height: 600px`, `width: 480px`, `top: 280px`, `top: 532px`, `top: 634px`, `left: 69px`. **Все** должны быть либо `fr`, либо `aspect-ratio`, либо переменные `--space-*`. Это самая большая системная задача — она тянется через всю страницу.
