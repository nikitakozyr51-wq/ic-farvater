## ЧАСТЬ 1 — Настройка (делать сейчас, до трафика)

### 1.1 Проверить что счётчик стоит на ВСЕХ страницах

Открой каждую страницу и проверь в коде наличие счётчика 109423767:

```
index.html
pages/about.html
pages/services.html
pages/products.html
pages/contacts.html
pages/connector-variant.html

pages/converter-variant.html
pages/transistors-detail.html
pages/microchips-detail.html
pages/pcb-detail.html

```

Как проверить быстро: открой страницу → правая кнопка → «Просмотр кода» → Ctrl+F → ищи `109423767`.
Если нашёл — счётчик есть. Если нет — добавить перед `</head>`.

### 1.2 Настройка целей (Цели → Добавить цель)

Цели = конкретные действия посетителей которые важны для бизнеса.
Без целей Метрика просто считает просмотры — это бесполезно.

**Идём в:** metrika.yandex.ru → счётчик 109423767 → Настройка → Цели → Добавить цель

#### Цель 1: Клик по телефону

| Поле | Значение |
|------|----------|
| Название | Клик по телефону |
| Тип | JavaScript-событие |
| Идентификатор | phone_click |

После создания — добавить в HTML на все кнопки с телефоном:

```html
<!-- Было: -->
<a href="tel:+79967788842">+7 (996) 778-88-42</a>

<!-- Стало: -->
<a href="tel:+79967788842" onclick="ym(109423767,'reachGoal','phone_click')">
  +7 (996) 778-88-42
</a>
```

#### Цель 2: Клик по email

| Поле | Значение |
|------|----------|
| Название | Клик по email |
| Тип | JavaScript-событие |
| Идентификатор | email_click |

```html
<!-- Было: -->
<a href="mailto:info@ic-farvater.ru">info@ic-farvater.ru</a>

<!-- Стало: -->
<a href="mailto:info@ic-farvater.ru" onclick="ym(109423767,'reachGoal','email_click')">
  info@ic-farvater.ru
</a>
```

### 1.3 Включить Вебвизор

Метрика → Настройка → Счётчик → вкладка «Вебвизор» → поставить галочку «Вебвизор».

Вебвизор записывает видео поведения каждого посетителя (как мышкой водил, что читал, где остановился).
Это самый ценный инструмент для понимания почему люди уходят со страницы.

**Важно:** Вебвизор использует ресурсы — включи только если трафик будет до 10000 сессий/мес.
При большем трафике можно ограничить до 10-20% сессий.

---

### 1.4 Фильтр собственных посещений

Чтобы твои визиты (разработчика) не портили статистику:

Метрика → Настройка → Фильтры → Добавить фильтр → «Фильтровать собственные визиты» → по IP.

Узнать свой IP: зайди на 2ip.ru, скопируй цифры.

---

### 1.5 Привязать к Яндекс.Вебмастер

Метрика → Настройка → Связанные сервисы → Вебмастер → привязать ic-farvater.ru

Что даёт: в Метрике появятся данные по поисковым запросам (по каким словам приходят люди).
Это критично для понимания что работает в SEO.

**Порядок:** Сначала добавить сайт в Яндекс.Вебмастер (webmaster.yandex.ru) → подтвердить право
на сайт → потом привязать к Метрике.

### 1.6 UTM-параметры для статей

Когда будешь публиковать статьи на Habr/VC.ru — ссылки на сайт должны содержать UTM-метки.
Иначе трафик с них будет считаться «прямым» и ты не поймёшь что работает.

**Формат ссылки:**

```
https://ic-farvater.ru/?utm_source=habr&utm_medium=article&utm_campaign=ekb-content-2026&utm_content=статья-01
```

| Параметр | Habr | VC.ru | Spark.ru | Dzen |
|----------|------|-------|----------|------|
| utm_source | habr | vc | spark | dzen |
| utm_medium | article | article | article | article |
| utm_campaign | ekb-content-2026 | ekb-content-2026 | ekb-content-2026 | ekb-content-2026 |
| utm_content | номер-статьи | номер-статьи | номер-статьи | номер-статьи |

Генератор UTM: tools.yaroshenko.by/utm/ (бесплатный, русский интерфейс)

## ЧАСТЬ 2 — Что смотреть когда появится трафик

### 2.1 Еженедельный мониторинг (каждый понедельник, 10 минут)

**Метрика → Сводка:**

| Показатель | Нормально | Тревога |
|------------|-----------|---------|
| Отказы | < 50% | > 65% |
| Глубина просмотра | > 1.8 стр | < 1.3 стр |
| Время на сайте | > 1:30 | < 0:45 |
| Достижение цели «Клик по телефону» | растёт | 0 за неделю при наличии трафика |

**Что делать при высоком показателе отказов (>65%):**
1. Открой Метрика → Вебвизор → посмотри 5-10 записей с отказами
2. Обрати внимание: закрывают сразу или смотрят несколько секунд?
3. Если закрывают сразу: возможно, страница медленно грузится или не совпадает с запросом
4. Если смотрят 10-20 сек и уходят: контент не отвечает на вопрос

### 2.2 Ежемесячный анализ

**Метрика → Источники → Поисковые системы:**
- Какой процент трафика из Яндекс?
- Растёт ли органический трафик?

**Метрика → Источники → Метки UTM:**
- Сколько пришло с Habr/VC.ru?
- Есть ли конверсии (звонки, письма) с этого трафика?

**Метрика → Технологии → Устройства:**
- Соотношение десктоп/мобильный
- Если мобильных > 30% — убедиться что мобильная версия удобна

**Метрика → Аудитория → Новые и вернувшиеся:**
- Есть ли возвращающиеся? (признак что сайт полезен)

### 2.3 Связка Метрика + Вебмастер (для SEO)

После привязки в Метрике появится вкладка **Поисковые запросы** (под Источниками).
Там видно:
- По каким запросам приходят из Яндекса
- Какие позиции занимают страницы
- CTR (сколько % кликают по ссылке в поиске)

**Что делать с этими данными каждый месяц:**

| Сигнал | Действие |
|--------|----------|
| Запрос даёт показы но CTR < 3% | Переписать title и description страницы |
| Запрос в позиции 8-15 | Улучшить контент страницы под этот запрос |
| Неожиданный запрос с трафиком | Создать отдельную страницу под него |
| Высокий отказ с конкретного запроса | Страница не отвечает на этот запрос — переделать |

## ЧАСТЬ 3 — Поведенческие факторы и Яндекс

Яндекс использует данные Метрики для ранжирования. Это официально подтверждено.

**Что Яндекс измеряет:**

1. **Время на сайте после перехода из поиска** — чем дольше, тем лучше
   → Как улучшить: добавить таблицы с данными, расширить описания продуктов, добавить FAQ

2. **Возврат в поиск (пого-стик)** — если вернулись быстро — плохой сигнал
   → Как улучшить: страница должна СРАЗУ отвечать на запрос, без "воды" в начале

3. **Достижение цели** — позвонили или написали = Яндекс понимает что сайт решил задачу
   → Как улучшить: цели в Метрике должны быть настроены (выше)

**Целевые значения для нашей ниши B2B ЭКБ:**

| Метрика | Цель | Как достичь |
|---------|------|-------------|
| Время на сайте | > 2:00 | Больше контента, таблицы, технические детали |
| Отказы | < 45% | Чёткий ответ на запрос в первом абзаце |
| Глубина | > 2.0 | Перелинковка между продуктами и статьями |
| Конверсия в звонок | > 0.5% | Заметный телефон, призыв к действию |

## ЧАСТЬ 4 — Чего НЕ делать в Метрике

❌ **Не смотреть только на число визитов** — абсолютные числа ничего не говорят на старте
❌ **Не паниковать при высоком отказе на первых неделях** — нет данных для нормы, нужно 30+ дней
❌ **Не сравнивать себя с конкурентами** — у каждой ниши своя норма
❌ **Не добавлять сайт в «Антибот-фильтры»** — это срежет реальный трафик
❌ **Не удалять данные** — даже плохие данные ценны для анализа

## ЧАСТЬ 5 — Временные рамки: когда ждать результатов

| Период | Что происходит в Метрике |
|--------|--------------------------|
| Неделя 1-2 | Почти нет данных, счётчик только собирает |
| Месяц 1 | Виден базовый трафик, источники, устройства |
| Месяц 2-3 | Можно анализировать поведение, отказы по страницам |
| Месяц 3-6 | Связка Метрика+Вебмастер даёт картину по запросам |
| Месяц 6+ | Полная картина: что работает, что нет |

**Главный принцип:** Метрика не улучшает SEO сама по себе. Она показывает ЧТО надо улучшить.
Улучшение происходит когда меняешь сайт на основе данных.
