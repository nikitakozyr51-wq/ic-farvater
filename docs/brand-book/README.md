# IC Фарватер — Бренд-бук · как пользоваться

Это папка с дизайн-системой (бренд-буком) IC Фарватер. Здесь два артефакта об одном и том же — текстовый и визуальный.

## Что где лежит

```
docs/brand-book/
├── IC-BRAND-BOOK.md     ← ТЕКСТ: все правила, токены, числа, источники
├── README.md            ← этот файл
├── CHANGELOG.md         ← версии + лог расхождений
└── site/                ← ВИЗУАЛЬНЫЙ бренд-бук (показывать заказчику)
    ├── index.html       ← открыть двойным кликом
    ├── brandbook.css
    ├── brandbook.js
    ├── assets/          ← шрифты Inter + логотип
    └── downloads/       ← ic-tokens.css (файл токенов) и пр.
```

## Как открыть (для заказчика)

Открыть [`site/index.html`](site/index.html) **двойным кликом** в любом браузере. Интернет не нужен — всё внутри: шрифты, стили, скрипты. Можно заархивировать папку `site/` и переслать — будет работать у любого получателя.

В бренд-буке:
- кликните по цвету → его код скопируется в буфер;
- кликните по строке тип-шкалы → скопируется её спецификация;
- листайте слева оглавление (разделы 00–17).

Сделать PDF: открыть `site/index.html` → **Печать** → «Сохранить как PDF».

## Для исполнителя (разработчика)

- **Источник правды — `IC-BRAND-BOOK.md`.** Все значения трассируются к живому коду сайта (`css/variables.css`, `css/base.css`, `css/components.css`, `css/mobile.css`). В скобках указан `Источник:`.
- **Эталон — живой сайт `d:\site`** (UPPERCASE-типографика, H1 72px), а НЕ старый `docs/design-research/IC-V4-DESIGN-SYSTEM.md` (он описывает невыпущенный Pencil-макет, его не трогаем).
- **Токены** для переиспользования — [`site/downloads/ic-tokens.css`](site/downloads/ic-tokens.css) (байт-копия `css/variables.css`).
- Микросайт **намеренно несёт собственную копию токенов и шрифтов** ради портативности и стабильности снимка.

## Как держать в синхроне

Бренд-бук фиксирует выверенный снимок живого сайта. Если на сайте меняются токены или типографика:

1. Открыть `css/variables.css` и `css/base.css` / `css/mobile.css`.
2. Сверить значения с разделами (04)–(06) в `IC-BRAND-BOOK.md` и с `:root{}` в `site/brandbook.css` + `site/downloads/ic-tokens.css`.
3. При расхождении — обновить бренд-бук и записать в [CHANGELOG.md](CHANGELOG.md). Любой дрейф = баг.
