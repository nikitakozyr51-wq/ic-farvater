## 1.0 — 2026-05-29
- Первый бренд-бук IC Фарватер (полная дизайн-система бренда).
- Два артефакта: `IC-BRAND-BOOK.md` (источник правды) + `site/` (визуальный микросайт).
- Эталон = живой сайт (UPPERCASE, H1 72px, контейнер 1920/60, self-hosted Inter).
- Логосистема — каркас под будущий знак (новый логотип не рисуем).
- Главы 00–17; применения: презентации, документы, соцсети, печать/маркировка ЭКБ, носители.
- Создан через `/design`. Старый `docs/design-research/IC-V4-DESIGN-SYSTEM.md` НЕ тронут.
