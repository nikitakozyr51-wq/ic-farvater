Суть бренда

(01)

Кто мы, для кого работаем и каким должен ощущаться бренд во всех материалах.

Коротко

Прямой поставщик и интегратор электронной компонентной базы (ЭКБ) в Санкт-Петербурге. Характер бренда — «точность + премиум»: инженерная надёжность B2B, поданная на премиальном студийном уровне.

Спецификация

Кто мы / для кого

  • Продукция: микросхемы, разъёмы (ЕТ-серии), СВЧ-компоненты (ARC70, LDMOS), преобразователи напряжения, печатные платы.
  • Услуги: прямые поставки, импортозамещение, кабельные сборки, испытания в партнёрской лаборатории «ЭКБ ТЕСТ».
  • Аудитория: B2B — ОПК, авиация, космос, телекоммуникации, промышленная электроника.

Характер и ценности

  • Точность + премиум. Воздух, сдержанность, внимание к детали. Ориентиры по уровню — Apple, Teenage Engineering, befree.
  • Достоверность. Никаких выдуманных заявлений; числа — только из проверяемых источников.
  • Чем мы НЕ являемся: не маркетплейс, не кричащий рекламный бренд. Без клише и визуального шума.

Голос и тон

(02)

Текст — часть айдентики. Главная глава по дисциплине: регистр, неразрывные пробелы, знаки, запрещённые формулировки.

Коротко

Говорим фактами, без рекламных клише. Главное правило набора — никаких висящих предлогов. Заголовки и большинство подписей — ЗАГЛАВНЫМИ.

Спецификация

Регистр (как на живом сайте)

  • Заголовки H1–H3 и большинство подписей/nav/footer — UPPERCASE через text-transform. В HTML регистр оригинала сохраняем (SEO/a11y).
  • Не «капсим» силой: «Айси Фарватер», SKU (ARC70, LDMOS, ЕТ-СНЦ23), аббревиатуры (КП, ИНН, ОГРН, ISO 9001).

NBSP — неразрывный пробел (hard rule)

&nbsp; обязателен после коротких служебных слов во всех текстах. Подтверждено в живом коде: «В САНКТ-ПЕТЕРБУРГЕ», «со склада», «по ГОСТ».

ДлинаСлова, после которых ставим NBSP
1 букваа в и к о с у я
2 буквыво за из ко на не об от по со до но же ни то бы ли
3 буквыдля или при что под над без про

Знаки

  • En-dash – для диапазонов: «1–3 рабочих дня», «до +200°с».
  • °с — строчными (не «°C»). Кавычки — «ёлочки». Разделитель «·» (middot).

Флаг расхождения · см. (17)

Сейчас на живом сайте присутствуют «согласование с военной приёмкой» и «категория качества «ВП»» (index.html и schema.org). Бренд-бук фиксирует дисциплину как рекомендацию; правка живого текста — отдельное решение заказчика.

Verified-OK (можно использовать)

  • «ЭКБ ТЕСТ» · ISO 9001 · «5000+ позиций аналогов» · «1–3 рабочих дня» · «5–10 рабочих дней».
  • Отрасли: «ОПК, авиация, космос, телекоммуникации» (общая формула).

Логосистема

(03)

Каркас под будущий знак. Текущий вордмарк + правила, в которые любой новый логотип легко встанет.

Коротко

Сейчас логотип — текстовый вордмарк «IC FARVATER». Полноценный знак планируется позже, поэтому фиксируем правила: воздух вокруг, минимальный размер, цвета, чего нельзя.

Спецификация

Текущие активы и цветоверсии

IC FARVATER
IC FARVATER

Вордмарк (Inter 500–700, латиница — основной, кириллица «IC ФАРВАТЕР» — вторичный) · леттермарк-квадрат из favicon (rx=10 — единственное скругление-исключение). Пунктир = охранное поле. proposed для большинства правил.

Правила

  • Охранное поле: минимум = высота заглавной «I» со всех сторон.
  • Мин. размер: вордмарк ≥16px / 6 мм; леттермарк ≥24px (favicon-safe).
  • Цвета: navy на светлом · cream на navy/фото · моно ч/б. Без градиентов, теней, обводок.
  • Слот под будущий знак: моно-first, favicon-safe 16px, только navy/cream, сочетание с Inter.

Принципы лейаута

(07)

Полноширинный hero, секции через тонкую линию, чередующиеся 2-кол сплиты, один drenched-подвал.

Спецификация
  • Hero: фото на всю ширину, 780px (mobile 400), контент прижат к низу, H1 в белом варианте.
  • Граница секций: верхний hairline 1px #D7D3CB через .section--bordered.
  • 2-кол сплиты: about-block (фото справа) ↔ cables-split (фото слева, зеркало); 50/50 → stacked на mobile.
  • Service split: левая колонка (заголовок + lead + CTA) + правый аккордеон.
  • Подвал: один drenched-navy: контакты + nav + мега-вордмарк + нижняя строка.

Источник: index.html l.77–446; css/components.css.

Иконки и UI-знаки

(08)

Только линии, один цвет, без заливки. Фирменные знаки бренда.

Спецификация · живые знаки

Плюс / минус

Поиск
  • Маркер-скобка: неактивно «( )», активно/hover «(•)» — ссылки подвала, радио-фильтры.
  • Плюс/минус: две линии 1px (::before/::after), при открытии вертикальная исчезает.

Изображения и фото

(09)

Компоненты на светло-сером фоне, не обрезаются. Hero/баннеры — по кадру. Чисто, индустриально, прохладно-нейтрально.

Спецификация
  • Подложка/плейсхолдер: --color-bg-alt #E9E8EB.
  • object-fit: contain — каталог/карточки (компонент не обрезается); cover — hero, баннеры, секционные фото.
  • Пропорции: карточка 1:1 · bottom-card 3:2 · hero широкий. Формат webp, loading="lazy" (кроме hero).
  • Hover: scale(1.06). Без overlay-scrim и цветных вуалей.
  • proposed Будущая съёмка: ровный свет, нейтрально-холодный баланс, акцент на текстуру металла/керамики, единый масштаб в рядах.

Источник: components.css; products.css.

Анимация

(10)

Сдержанное, плавное движение. Уважает «меньше движения».

Спецификация
  • Easing: cubic-bezier(0.16, 1, 0.3, 1); длительности 0.2–0.7s.
  • Паттерны: fade-up / stagger, scale-reveal, split-text, line-draw; карточка translateY(-6px) + фото scale(1.06); аккордеон 0fr→1fr.
  • Только GPU-свойства (transform, opacity). Уважается prefers-reduced-motion.
  • Движок: Lenis + GSAP + ScrollTrigger.

Источник: index.html l.448–452; animations.css. (Этот бренд-бук сам использует fade-up — пример живой.)

Доступность

(13)

Управление с клавиатуры, читаемость скринридером, уважение к режиму «меньше движения».

Спецификация
  • Фокус: outline: 2px solid navy + offset 2px на :focus-visible.
  • ::selection navy/cream · .sr-only для скринридеров · prefers-reduced-motion.
  • Все изображения с alt; loading="lazy" (кроме hero); семантика h1→h3.
  • Шрифты self-hosted (ФЗ-152); cookie-consent + privacy/consent.
  • proposed для длинного body предпочитать #112F6E вместо #6B7A94 (контраст).

Источник: base.css l.75–117; animations.css.

Do / Don't

(15)

Сводные гардрейлы. Если сомневаетесь — сверьтесь здесь.

✓ Делать
  1. 5 цветов палитры; контраст navy↔cream.
  2. Inter везде; заголовки UPPERCASE, weight 500, отрицательный трекинг.
  3. &nbsp; после коротких предлогов/союзов.
  4. Отступы кратны 8px.
  5. Кнопки — пилюли (100px); всё иначе без скруглений.
  6. Один drenched-navy блок на страницу.
  7. Счётчики секций — round (NN).
  8. Фото компонентов — contain на #E9E8EB.
  9. Каждое число — из проверяемого источника.
✗ Нельзя
  1. Тени, градиенты, blur.
  2. Яркие акценты вне палитры.
  3. Скругления у не-кнопок (кроме леттермарка).
  4. Размеры шрифта вне тип-шкалы.
  5. Висящие предлоги.
  6. Выдуманные заявления (см. 02).
  7. object-fit: cover для каталожных фото.
  8. Резкие hover-эффекты сверх заданного.
  9. Сторонние шрифты / Google Fonts.
